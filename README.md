# Kuznets Curve Panel Evidence from India

This project analyzes the Environmental Kuznets Curve (EKC) hypothesis using panel data from Indian states (2004–2020).

## Methodology

* Fixed Effects (FE) and Random Effects (RE) models
* Hausman test for model selection
* Log transformations and centered GDP terms
* Clustered standard errors
* Residual diagnostics

## Variables Used

* PM2.5 (Air Pollution)
* GDP
* Vehicles
* Electricity Consumption
* Number of Factories
* Forest Cover

## Tools

* Stata (Panel Data Econometrics)

## How to Run

1. Place the dataset (`EKC_Data.xlsx`) in the working directory
2. Run the `.do` file in Stata
